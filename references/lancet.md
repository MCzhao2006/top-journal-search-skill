# The Lancet Adapter

## Scope

Unqualified `The Lancet` means the flagship journal. Expand only when the user asks for the Lancet family (for example The Lancet Oncology, The Lancet Infectious Diseases, The Lancet Digital Health, etc.).

Official domain: `thelancet.com` (Elsevier/Lancet Group infrastructure may link to ScienceDirect or support pages).

## Search behavior

Use the site's search box / advanced search first. Lancet pages historically expose `action/doSearch` style URLs, but treat URL parameters as implementation details that may change. If the site UI is inaccessible, use a domain-restricted web search plus Crossref/PubMed discovery.

## Lancet-specific verification

- Verify whether the paper is in `The Lancet` flagship or a specialty Lancet journal.
- Record article type (Article, Review, Seminar, Comment, Correspondence, Commission, etc.).
- For clinical evidence, check registration, design, population, primary outcome, and whether conclusions match the design.
- PubMed is often a strong fallback for Lancet-family discovery and abstracts.
