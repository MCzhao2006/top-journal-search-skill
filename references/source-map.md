# Cross-Publisher Source Map

## Source hierarchy

For article identity and journal-specific facts:

1. Official publisher article page
2. Official publisher search/archive/issue page
3. Crossref DOI metadata
4. PubMed / Europe PMC for biomedical indexing and abstracts
5. Other scholarly indexes for discovery
6. General web search restricted to the official domain

For a substantive scientific claim, open the actual abstract/full text when accessible. Metadata alone is not sufficient to judge claim support.

## Flagship vs family

| User wording | Default scope |
|---|---|
| Nature | `Nature` flagship only |
| Nature family / Nature Portfolio | Nature Portfolio titles |
| Science | `Science` flagship only |
| Science journals / AAAS journals | Science family titles |
| The Lancet | `The Lancet` flagship only |
| Lancet family | Lancet specialty journals too |
| NEJM | `The New England Journal of Medicine` |
| JAMA | `JAMA` flagship only |
| JAMA Network | JAMA + specialty journals + JAMA Network Open |
| Cell | `Cell` flagship only |
| Cell Press | Cell Press portfolio |
| PNAS | `Proceedings of the National Academy of Sciences` |
| PNAS + Nexus | Include `PNAS Nexus` |

## DOI prefixes as hints, not proof

Common DOI prefixes can help discovery but must not replace journal verification:

- Nature Portfolio often uses `10.1038/...`
- Science often uses `10.1126/...`
- Lancet and Cell Press commonly use `10.1016/...`
- NEJM uses `10.1056/...`
- JAMA uses `10.1001/...`
- PNAS commonly uses `10.1073/...`

A DOI prefix identifies a registrant/publisher pattern, not necessarily the exact journal.
